cpp-http-server

A small HTTP/1.1 server written in C++17 on plain Linux sockets. It can run with a blocking thread pool or a non-blocking epoll loop, and serves this page from its --root directory.

Endpoints

  • GET /health liveness check
  • GET /api/stats uptime, mode, connection and request counters
  • GET /api/time current server time (UTC)
  • GET /api/users/:id path parameter example
  • POST /api/echo returns the request details and body as JSON
  • GET /file16k.bin a 16 KiB static file
